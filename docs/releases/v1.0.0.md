## minicplex 1.0：用 C++17 从零实现的迷你 CPLEX

第一个正式版本。零依赖，能读 CPLEX `.lp` 文件、能用 C++ 建模，求解线性规划（LP）和混合整数规划（MIP）。结果由 HiGHS 自动对拍验证。

### 亮点

- **有界变量单纯形**：变量上下界不占约束行，也不需要人工变量
- **对偶单纯形热启动**：分支后子节点从父节点的单纯形表继续，几步就能重新求优
- **下潜式分支定界**：沿取整方向一路下潜；对偶目标超过当前最优解就立刻剪枝
- **CPLEX 兼容**：读写 LP 文件，命令行和节点日志风格接近 CPLEX
- **Concert 风格 API**：`m.addConstr(2 * x + 3 * y <= 12)`

### 性能（`bench/` 中 13 个模型，对比早期 v0.1 内核）

| 指标 | v0.1 | v1.0 |
|---|---|---|
| 单纯形迭代 | 777,609 | 40,804（少 95%） |
| 总用时 | 2.78 秒 | 约 0.6 秒（CI 机器上快 6.9 倍） |
| 餐厅排班例子 | 1.03 秒 | 0.02 秒 |

### 正确性

- 单元测试、例子冒烟测试、基准模型：Release 和 AddressSanitizer + UBSan 两种构建全部通过
- 约 6,000 道随机题（混合整数、纯 LP、多维背包）与 HiGHS 逐题一致；每次提交 CI 自动再对拍 500 道
- 500 道随机整数题与暴力枚举一致
- 对拍中还发现 HiGHS 的一处错误：一道 LP 松弛无界的整数题被它报成“最优 41”，实际可以无限下降。minicplex 正确报告“不可行或无界”

### 快速开始

```bash
cmake -S . -B build && cmake --build build -j
ctest --test-dir build
./build/minicplex examples/facility.lp
```

### 已知限制

- 使用稠密单纯形表，适合几百行 / 列规模的模型
- 暂不支持二次规划、SOS、半连续变量、MPS 文件、范围约束
