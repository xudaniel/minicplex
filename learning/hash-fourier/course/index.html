搅乱，
与分开

Hash 把一句话搅成一串指纹，再也回不去。傅里叶把混在一起的波一根一根分出来，还能原样拼回去。这页里的每个数字，都是你的浏览器照着那几个 C 文件的算法现场算的。

上半场 搅乱

Hash：任意长的内容，压成固定长度的指纹。

01

指纹

随便写一句话。下面 256 个格子就是它的 SHA-256，每个格子是一位，黑的是 1。

SHA-256（256 位，64 个十六进制字符）
实际处理的字节数
FNV-1a（十行那个，32 位）
对应的 C 代码（simple_hash.c） 
unsigned int hash(const char *s) {
    unsigned int h = 2166136261u;   // 起点
    while (*s) {
        h ^= (unsigned char)*s++;   // 混入一个字节
        h *= 16777619u;             // 乘质数搅散
    }
    return h;
}

同一句话永远得到同一个指纹。hash 只认字节，不认字。

02

雪崩

把上面那句话改一点点，看指纹变了多少。红格子是变了的位。

原句（在实验 01 里改）
/ 256 位不同。虚线是一半，128。
变了的位没变，是 1没变，是 0
两个指纹，红字是不一样的字符
对应的 C 代码（hash_demo.c） 
static int pop32(u32 x) {            // 数有几个 1
    int n = 0;
    while (x) { n += x & 1; x >>= 1; }
    return n;
}
// 两个 hash 异或，1 的个数就是不同的位数
n += pop32((u32)(a[i] ^ b[i]));

改一位，变一半。相似的话得不到相似的指纹。

03

六十四轮

SHA-256 把 8 个数 a 到 h 搅 64 轮。拖滑块，一轮一轮看实验 02 那两句话是怎么分道扬镳的。

/ 256 位不同
对应的 C 代码（hash_demo.c） 
for (i = 0; i < 64; i++) {
    t1 = h + EP1(e) + CH(e,f,g) + K[i] + m[i];
    t2 = EP0(a) + MAJ(a,b,c);
    h = g; g = f; f = e; e = d + t1;   // 整体往后挪一格
    d = c; c = b; b = a; a = t1 + t2;  // 新值从 a 和 e 进去
}

四五轮就乱到一半。剩下五十多轮都是安全余量。

04

撞车

256 位撞不上，那就把指纹截短，只看前几位，现场找两句指纹相同的话。

只看 SHA-256 的前几位
指纹长度大约试多少句，有一半把握撞上
16 位约 300 句
32 位（FNV-1a）约 7.7 万句
64 位约 51 亿句
256 位（SHA-256）约 4 × 10³⁸ 句，也就是 2¹²⁸ 的量级

指纹长度翻倍，要试的次数变成原来的平方。

下半场 分开

傅里叶变换：一段信号里，每个频率各有多少。

05

混音

三个波加在一起。上图是混好的信号，下图是变换后的频谱。拖滑块，两张图一起动。

混在一起的信号（看时间） 傅里叶变换之后（看频率）：横轴是频率，柱高是振幅
对应的 C 代码（fourier.c） 
// 振幅 = |X[k]| × 2/N
double amp = my_sqrt(re[k]*re[k] + im[k]*im[k]) * 2 / N;

在时间上搅成一团的波，在频率上各站各的位置。

06

探针

变换是怎么分出来的？拿一个标准波当探针，和实验 05 的信号逐点相乘，再全部加起来。

信号 × 探针。横线上面的面积算正，下面的算负。
正的部分负的部分
× sin 波，加起来
× cos 波，加起来
合成的振幅
三个数都已除以 N/2，所以直接就是振幅。
对应的 C 代码（fourier.c） 
for (int k = 0; k < N; k++) {        // 每一个频率
    for (int n = 0; n < N; n++) {    // 每一个采样点
        re[k] += x[n] * my_cos(a);   // 和 cos 波的相似度
        im[k] -= x[n] * my_sin(a);   // 和 sin 波的相似度
    }
}

信号里有这个频率，乘积就累加；没有，就正负抵消。sin 和 cos 两根探针一起用，信号挪到哪都测得准。

07

对半拆

探针法要每个频率把所有点过一遍，N × N 次。FFT 把问题对半拆，再对半拆。拖滑块加点数，看两边差多少。

DFT
FFT
1一千一百万十亿一万亿
柱长按对数画：每一格是 1000 倍。
DFT 次数（N × N）
FFT 次数（N/2 × log₂N）
FFT 少算
按每秒 1 亿次估算
FFT 怎么拆：
对应的 C 代码（fft.c） 
fft(er, ei, h);                      // 偶数位那一半
fft(odr, odi, h);                    // 奇数位那一半
for (int k = 0; k < h; k++) {
    // t = w × 奇[k]：算一次，用两次
    re[k]     = er[k] + tr;
    re[k + h] = er[k] - tr;
}

每层只做 N/2 次，一共 log₂N 层。

08

回得去吗

最后把两样东西放在一起比。先给实验 05 的信号加上杂音，再用傅里叶把杂音拿掉。然后试着从指纹倒推原句。

傅里叶：变换，删掉高频，再反变换
加了杂音的信号拿掉高频之后原来干净的信号

Hash：从指纹倒推原句，只能一句一句瞎猜

傅里叶把回去的路留着，所以能修声音和图片。Hash 把路拆了，所以能验明正身。

记住三句

  1. Hash 是指纹：改一位变一半，撞不上，回不去。
  2. 傅里叶是分拣：拿标准波一个一个去探，有就累加，没有就抵消。
  3. 两个算法的核心都是几行循环，你今天都在 C 里见过了。
