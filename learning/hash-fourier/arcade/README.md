# 傅里叶游戏厅（Fourier Arcade）

四个围绕傅里叶变换的小游戏，一共十二颗星。每个游戏都在练同一件事：把一条弯弯曲曲的线，看成几个简单正弦波叠在一起。

整个游戏厅是一个 HTML 文件，用浏览器直接打开就能玩，手机和电脑都可以。右上角可以切换中文和英文。所有计算都在浏览器里现场运行，变换用的是和 `fourier.c` 一样的两层循环。

## 文件

| 文件 | 内容 |
|---|---|
| `index.html` | 游戏厅本身，单个文件 |
| `test.js` | 把页面里的算法取出来逐项检查 |

```bash
# 玩：用浏览器打开 index.html
# 检查算法：
node test.js index.html
```

## 四个游戏

### G1 调音（Tune It）

虚线是目标波形。拖动三个振荡器的频率和振幅，让你的波和目标完全重合。

- 频率 1 到 12，振幅 0 到 1（每格 0.05）。
- 重合度到 99.5% 算对上，实际上就是每个滑块都要拖到位。
- 五个关卡：热身（一个波）、两个波、三个波、像方波、随机。
- 「像方波」那一关的答案是奇数频率 1、3、5，振幅约为 1、1/3、1/5。这正是方波的开头几项。
- 可以听目标和自己的波：频率 f 对应 110 × f 赫兹。
- 卡住时可以打开目标的频谱当提示。

星星：对上「两个波」、「三个波」、「像方波」各一颗。

### G2 认谱（Spectrum Snap）

给一个波形和四张频谱，选出属于它的那一张。一局八轮：前三轮一个波，中间三轮两个波，最后两轮三个波。

错误选项是按常见的误解设计的，比如“两个频率会加在一起变成一根柱子”、“柱子高度对调”、“频率差一格”。

计分：

- 答对得 100 分。
- 速度加分最多 100 分，10 秒内线性减到 0。
- 连对加分：之前已经连对几题，就加几个 20 分。
- 答错得 0 分，连对清零。
- 八题全对并且瞬间作答，满分是 2160。

星星只看答对的题数：一局答对 5 题、7 题、8 题各一颗。

### G3 寻频（Frequency Hunt）

信号里藏着几个波。频率 1 到 16 排成一排格子，每点一格，就用那个频率去探一次，得到信号里这个频率的振幅。探针数量有限，要在用完之前把藏着的波全找出来。

| 关卡 | 藏着的波 | 探针 |
|---|---|---|
| 第 1 关 | 两个 | 6 根 |
| 第 2 关 | 三个 | 6 根 |
| 第 3 关 | 三个，起点各不相同 | 5 根 |

要点：

- 探错的结果正好是 0。哪怕只差一格，信号和探针的乘积也会完全抵消。
- 第 3 关的波挪过起点，所以会同时显示 sin 探针和 cos 探针的结果，两者合起来才是振幅。
- 每次探完，下面会画出“信号 × 探针”的曲线，可以看到面积是累加还是抵消。
- 每探中一个频率，会播放那个频率的声音。

星星：三关各一颗。

### G4 画圆（Circle Artist）

在画板上一笔画一个封闭的图形。程序把它拆成一串转动的圆，再用这些圆把图形重新画出来。拖滑块可以改变用几个圆，圆越少，画得越粗糙。

做法：

1. 把你画的线按长度均匀取 256 个点。
2. 把每个点看成一个复数，做一次傅里叶变换。每个系数就是一个圆：大小是半径，频率是转速，正负是方向。
3. 按半径从大到小排序，只用前 M 个圆来画。
4. 还原度由被丢掉的那些圆的能量算出来。

星星：

- 画一个只用 1 个圆就能还原 90% 的图形（画一个圆）。
- 画一个正好需要 2 个圆才到 90% 的图形（画一个椭圆）。
- 画一个需要 8 个以上的圆才到 95% 的图形。

校准时的一个意外发现：五角星只要 3 个圆就能还原到 95%，8 字形却要 8 个。所以第三颗星靠的是绕圈和交叉，不是尖角。示范用的心形到 90% 要 5 个圆，到 95% 要 8 个。

## 成绩和设置

- **成绩榜**在页面最下面，记录四个游戏各自的最好成绩：调音每关最快用时、认谱最高一局得分、寻频每关剩余探针数、画圆最圆和最复杂的一次。
- 拿满十二颗星后，成绩榜会变成通关卡片。
- 调音的计时从第一次拖动滑块开始。认谱每一轮的计时从四个选项出现在屏幕上开始。
- 右上角的 ♪ 可以关掉游戏音效。「听目标」和「听我的」两个按钮在静音时仍然能用。
- 星星、成绩、语言和声音设置只存在当前浏览器里，换一台设备不会带过去。

## 怎么核对的

`node test.js index.html` 检查这些：

- 调音：四个固定关卡按答案设置后重合度是 100%，差一格就低于 99.5%；300 个随机目标都能用滑块精确对上。
- 认谱：生成 3200 轮，每轮四个选项互不相同，正确选项的柱子和真正做变换算出来的一致。
- 寻频：900 个随机棋盘，藏着的频率探出来正好是它的振幅，其余频率正好是 0。
- 画圆：圆、椭圆、8 字形分别触发对应的那颗星；还原度随圆的数量只增不减，用完所有圆时是 100%。

另外用无头浏览器自动玩过一遍：调音对上两关，认谱打完一局，寻频赢一关、输一关，画板上用模拟的笔画画了三个图形，切换了声音和语言，全程没有报错。

没有核对过的：声音实际听起来怎么样。
