# 旅行行程 agent：一句话改行程

**中文** | [English](README.en.md)

「第三天想睡懒觉，十点前别安排。」说一句话，程序把三天行程重排一遍，告诉你少玩了多少、要不要找同行的人商量。

这是 [补班 agent](../staffing-agent/README.md) 的姊妹篇：五站流水线原样搬过来，只把会计手里的题换成「带时间窗的排程」，求解器从 SCIP 换成 CP-SAT（它天生擅长「时间段不能重叠」）。城市、景点、时间、分数全是虚构的。

## 跑起来

```bash
pip install ortools
cd learning/itinerary-agent
python3 itinerary_agent.py                 # 主角那句话，逐站打印
python3 itinerary_agent.py --all           # 主角 + 门卫拦下的话 + 两个翻车现场
python3 itinerary_agent.py -i              # 自己一句一句说，空行退出
python3 itinerary_agent.py --all --lang en # 英文版
python3 -m unittest -v test_itinerary_agent
```

## 墙上的规矩

- **三天：**第 1 天 15:00–21:00（下午才到），第 2 天 09:00–20:00，第 3 天 09:00–12:00（中午去机场）。
- **十个景点，分东、中、西三个区**，各有想去指数、玩多久、开放时间。
- **四条规矩：**景点之间路上 30 分钟；天守阁已买票，第 2 天 14:00 入场；整天的日子 11:30–13:00 之间要开吃午饭（中午去拉面横丁也算）；每天最多跑两个区。

原计划想去指数 60，美术馆和动物园排不下（十个景点总分 71，71 − 6 − 5 = 60）。

## 主角那一趟

```
第 1 站｜助理：{"type": "start", "day": 3, "value": 10}，收据「第三天想睡懒觉，十点前别」
第 2 站｜门卫：ok
第 3 站｜会计：第 1 天 15:00 千灯寺 → 17:30 温泉街
             第 2 天 09:00 竹林小径 → 10:30 观景台 → 12:00 拉面横丁 → 14:00 天守阁 → 18:00 夜市
             第 3 天 10:00 海边市场
第 4 站｜老师傅：没有黄灯
第 5 站｜秘书：想去指数 60（和原计划一样）。审批：自己定就行。
```

一分没少玩，但整个行程都换了：海边市场 13:00 关门，正好塞进第 3 天 10:00–12:00，于是从第 2 天早上挪到最后一天。程序会给每一站打 ✓：开门后才到、关门和收工前玩完、相邻两站隔够 30 分钟。

## 测试覆盖的情形

| 说法 | 结果 |
|---|---|
| 第三天想睡懒觉，十点前别安排 | 60，自己定 |
| 第二天下午五点前要回酒店 | 53，同行的人一起商量 |
| 环球影城一定要去 | 反问（名单里没有） |
| 第五天十点前别安排 | 拒绝（只有 3 天） |
| 美术馆一定要去，美术馆不去了 | 反问（自相矛盾） |
| 天守阁不去了 | 要确认；确认后 56，出钱的人批 |
| 动物园一定要去 | 58 |
| 😈 拿掉午饭规则 | 66，但老师傅亮灯：没空吃饭 |
| 😈 拿掉「每天最多两个区」 | 动物园那句变 59，一天跑三个区，亮灯 |

中英文各跑一套，数字必须一样。

## 模型

```
决定：x[s, d] 第 d 天去不去景点 s；st[s, d] 几点到
满足：开门后才到、关门和当天收工前玩完
      每个景点变成一段「可选时间段」（玩的时间 + 路上 30 分钟），同一天互不重叠（AddNoOverlap）
      午饭是一段 90 分钟的时间段，11:30–13:00 开始；中午去拉面横丁可以代替
      每天每个区一个开关，开关加起来 ≤ 2
目标：先比想去指数，同分时越早越好
```
