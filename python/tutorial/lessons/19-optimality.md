## 1. 求解器没有试遍所有方案

一道题有几十个整数变量，组合数就比宇宙里的原子还多，不可能一个个试。求解器能说“这是最优”，靠的是同时算两个数：

- **找到的最好答案**（下界，最大化时）：手里已经有一个可行方案，最优值至少这么大；
- **任何答案都超不过的上限**（上界）：有证据说明，再好的方案也到不了这个数。

两个数碰到一起，中间没有空隙了，就**证明**了最优。这一课就讲上限是怎么来的、怎么核对。

## 2. 线性规划：影子价格就是证书

例题：最大化 5x + 4y，限制 6x + 4y ≤ 24，x + 2y ≤ 6，x、y ≥ 0。

把例题写成 LP 文件（练习里的 `demo_model` 建的是同一个模型），用命令行解它的线性松弛并打印影子价格：

```bash
cd python && python3 -m minicplex demo.lp --relax --duals
```

求解器给出 x = 3、y = 1.5，目标值 21；同时给出两条约束的**影子价格** 0.75 和 0.5。拿它们给约束加权：

```text
0.75 × (6x + 4y) + 0.5 × (x + 2y) = 5x + 4y        ← 加权后的左边，正好是目标
0.75 × 24        + 0.5 × 6        = 21             ← 加权后的右边
```

所以对**任何**满足约束的 x、y，都有 5x + 4y ≤ 21。而 x = 3、y = 1.5 正好拿到 21，证毕。

要让这个推理成立，影子价格必须满足两个条件（就是练习里的 `dual_feasible`）：

- **不能是负数：** `<=` 约束两边乘一个负数，不等号就反了；
- **每一列加权后不小于目标系数：** x 那一列 6 × 0.75 + 1 × 0.5 = 5 ≥ 5，y 那一列 4 × 0.75 + 2 × 0.5 = 4 ≥ 4。

这就是**对偶定理**：线性规划的最优解总能配上这样一组影子价格，让两头相等。它的好处是：**证书谁都能手算核对，不用相信求解器**。在 minicplex 里，影子价格在 `r.duals`。

## 3. 整数规划：上下两头夹

要求 x、y 是整数时，y = 1.5 不行了。分支定界把问题拆成 y ≤ 1 和 y ≥ 2 两半分别解，一边找整数解，一边压上限。这是 minicplex 节点日志的要点（真实运行结果）：

| 节点 | 最好整数解 | 上限 | 间隙 |
|---|---|---|---|
| 2 | 18 | 21 | 16.67% |
| 3 | 19 | 20 | 5.26% |
| 5 | 20 | 20 | 0.00% |

（命令行日志里这三列叫 Best Integer、Best Bound、Gap，CPLEX 的日志也是这几列。）

- **Best Integer（最好整数解）**从 18 → 19 → 20 往上爬；
- **Best Bound（上限）**从 21 → 20 往下压。它是所有还没解完的分支里，线性规划上限的最大值——每个分支的上限都有第 2 节那样的证书；
- **Gap（间隙）**= |上限 − 最好整数解| / |最好整数解|，两头碰上就是 0。

minicplex 判断“碰上了”的代码（[`solver.py`](../../minicplex/solver.py)）：

```python
return incumbent - bound <= max(P.mip_abs_gap, P.mip_gap * max(1.0, abs(incumbent)))
```

（minicplex 内部统一按最小化写，所以是“最好解 − 下界”；练习里按最大化写，方向反过来。）

## 4. 三个要小心的地方

- **“最优”是在容差内：** 默认允许百万分之一的相对差距（`Params.mip_gap`，对应 CPLEX 的 EpGap）。小数运算本来就有误差（第 2 课），要求分毫不差反而永远停不下来。
- **提前停下的只是“好解”：** 设了 `time_limit` 或 `node_limit`，停下时 Gap 还大于 0，结果就只是一个可行的好方案。日志里的 Gap 告诉你最多还差多少——这是练习里那道 🤔 题。
- **还要防假解：** 每找到一个整数解，minicplex 都用原始模型把每条约束重查一遍（`check_feasible`，第 13 课），不满足就扔掉。

## 5. 博弈也一样：保底和封顶

零和博弈也能这样证明。练习里写好了一个点球博弈（数字是虚拟的）：射门方按左 41%、中 13%、右 47% 随机，不管门将扑哪边，进球率**至少** 78.1%（保底）；门将按左 37%、中 20%、右 43% 随机，不管射门方往哪踢，进球率**至多** 78.1%（封顶）。保底 = 封顶，双方都是最优。门将的概率，正好是射门方那个线性规划的影子价格——这就是冯·诺依曼的极小极大定理和对偶定理是同一件事的原因。

## 7. 想一想

如果第 2 节的影子价格换成 1 和 0，能证明什么？

<details><summary>答案</summary>

x 那一列 6 × 1 + 1 × 0 = 6 ≥ 5，y 那一列 4 × 1 + 2 × 0 = 4 ≥ 4，而且都不是负数，所以它也是合格的证据，能证明 5x + 4y ≤ 1 × 24 + 0 × 6 = 24。
上限 24 是对的，只是比 21 松。**任何**合格的影子价格都能给出一个上限；最优的那一组给出最紧的上限，正好等于最优值。找最紧的那组，本身又是一个线性规划，叫**对偶问题**。

</details>
