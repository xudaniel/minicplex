## 1. 变量：给一个值起名字

```python
price = 4        # 本子 4 元
count = 3
total = price * count
print(total)     # 12
```

`=` 不是“等于”，而是“把右边的值放进左边的名字里”。所以 `count = count + 1` 完全合法：先算右边，再放回去。
它还可以简写成 `count += 1`。

变量名用英文字母、数字和下划线，不能以数字开头。Python 的习惯是全小写、单词之间用下划线：`order_total`、`max_steps`。

## 2. 两种数字

| 写法 | 类型 | 例子 |
|---|---|---|
| 没有小数点 | `int`（整数） | `3`、`-7`、`2026` |
| 有小数点 | `float`（小数） | `6.5`、`0.1`、`3.0` |

Python 的整数没有大小限制：`2 ** 100`（2 的 100 次方）也能精确算出来。小数就没那么完美了，第 2 课会讲 `0.1 + 0.2` 为什么不等于 `0.3`。

## 3. 除法有三种

```python
10 / 3     # 3.3333333333333335   普通除法，结果总是小数
10 // 3    # 3                    整除：只要整数部分（向下取整）
10 % 3     # 1                    取余数
```

“10 元能买几个 3 元的东西”用的是 `//`，“还剩几元”用的是 `%`。

> **minicplex 里的例子：** 求解器把一个 m 行 n 列的表格存成一长串数，第 k 个数在第 `k // n` 行、第 `k % n` 列（第 3 课会讲）。

## 4. 常见错误

- 把 `=` 当成“比较”：比较两个值是否相等要用 `==`（A3）。
- 想要整数却用了 `/`：`10 / 2` 是 `5.0`（小数），不是 `5`。
- 括号：`(a + b + c) / 3` 和 `a + b + c / 3` 不一样，乘除先算。

## 6. 想一想

`-7 // 2` 是多少？是 `-3` 还是 `-4`？

<details><summary>答案</summary>

是 `-4`。`//` 是**向下**取整（往负无穷方向），不是“去掉小数点后面”。`-3.5` 向下取整是 `-4`。
同样，`-7 % 2` 是 `1`，因为 `-4 × 2 + 1 = -7`。很多别的语言（C、Java）在这里会得到 `-3` 和 `-1`，换语言时要小心。

</details>
