## 1. 变量：带名字的盒子

```java
int apples = 3;          // 整数
double price = 2.5;      // 小数
String name = "Mia";     // 文字
apples = apples + 1;     // 盒子里的值可以换：现在是 4
```

写法是 **类型 名字 = 值;**。Java 要求先说清楚盒子装什么类型，装错了编译就不过。

| 类型 | 装什么 | 例子 |
|---|---|---|
| `int` | 整数 | 个数、天数、分数 |
| `double` | 小数 | 价格、温度、平均数 |
| `String` | 文字 | 名字、句子 |
| `boolean` | 真或假 | 钱够不够、是不是周末 |

## 2. 计算

| 写法 | 意思 | 例子 |
|---|---|---|
| `+ - *` | 加、减、乘 | `3 * 2` 是 `6` |
| `/` | 除 | `10 / 4` 是 `2`（整数相除！） |
| `%` | 余数 | `10 % 3` 是 `1` |

## 3. 最常见的坑：整数除法

**两个整数相除，结果还是整数，小数部分直接丢掉**：

```java
10 / 3      // 3，不是 3.33
7 / 2       // 3，不是 3.5
7 / 2.0     // 3.5   ← 只要有一边是小数，结果就是小数
```

这个规则有时正好有用：10 元钱、3 元一个，最多买 `10 / 3 = 3` 个，还剩 `10 % 3 = 1` 元。

## 4. 常见错误

- 算平均数写成 `(a + b) / 2`，7 和 8 的平均数变成了 7。要写 `/ 2.0`。
- 变量没声明就用：`total = 5;` 前面要先有 `int total;`。
- 把 `=` 当成“等于”：`=` 是“把右边的值放进左边的盒子”，比较相等要用 `==`（下一课）。

## 6. 想一想

-7 / 2 是多少？

<details><summary>答案</summary>

`-3`。Java 的整数除法是“向 0 取整”，直接去掉小数部分（−3.5 → −3），不是向下取整。minicplex 里需要向下取整时，用的是 `Math.floor`（第 2 课会讲）。

</details>
